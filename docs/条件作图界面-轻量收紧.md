# 按条件作图界面轻量收紧

日期：2026-10-25；源码版本保持0.6.0，不发布。

## 界面分层

- 保留左侧编辑、右侧常驻预览，以及完整输入和简写两条录入路径；窄窗口允许上下排列。
- 平面模式靠标题；题干识别保留直接入口；配置加载和保存使用原有协议，入口合并为配置菜单。
- 添加对象表单按需展开，成功后收起。对象列表显示定义与已知/待求状态，选中对象再展开待求字段和范围；使用当前编辑上下文反映勾选状态。
- 有坐标的点名/补充线段收到批量声明；无坐标与立体保留紧凑输入。空曲线列表仅显示添加按钮。圆、变量、向量的新增表单不在本轮扩展。
- 坐标条件表单移入完整输入“坐标 / 曲线”分类，仍使用原编译入口。插入角默认收起，符号插入和分页保留。
- 条件可点击编辑，Enter完成、Esc取消本次编辑；立体编辑恢复进入编辑时的源码，而不是丢失此前已确认修改。删除按钮在悬停/键盘聚焦显示，触屏常显。
- 求解状态及方式在预览下汇总。构型与运动/轨迹分组，单构型不展示下拉；本工作区不再显示“编辑条件”自指按钮，主画布对象详情继续保留编辑入口。
- 详细求解原因、诊断和代数根折叠。深入搜索位于详情，暂未找到时状态区也给入口；底部保留撤销、状态和最终确认。立体放置独立折叠并显示摘要。

## 识别核对

- embedded现在是真正的预览展示形态：不挂载编辑器、文件入口、提交区和运动控制，复用相同图形及状态渲染；保留必要全图与空间旋转。
- 三种识别操作不合并、不自动触发云端；按钮仍受截图、题文与忙碌状态约束。
- 原文与转换条件并排，角色、小问、重框、删除与源码放入单条编辑区。
- 错误按条目显示，汇总提供定位；提示默认折叠。识别条件错误时保留上次有效预览并禁止导入；更换截图清除旧预览。
- 差异列表按新增/修改/删除显示可读条件。优先稳定ID，其次同作用域内唯一的原文/源码/说明匹配；歧义不强行配对，不跨兄弟小问。匹配失败按新增与删除呈现。保留替换确认，最终提交仍单独确认。
- 百炼设置使用独立遮罩弹层，Esc关闭并限制Tab焦点范围；不更改密钥存储或云端逻辑。
