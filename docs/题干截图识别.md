# 题干截图识别、全文与条件来源

更新：2026-10-25。本功能保留 0.5.1 版本号，不自动发布。

## 使用

1. 运行原来的 `启动数学绘图.command`。
2. 打开“按条件作图 → 从题干截图导入”。首次在“百炼设置”填 API Key、地域；按用户要求，Key 现在仅保存在本机应用配置文件，不使用钥匙串。
3. 点击“选择截图”使用系统文件对话框，或点击“粘贴截图”/在识别窗口按 ⌘/Ctrl+V 读取剪贴板图片；支持 PNG/JPEG，可裁剪，然后点击“识别题干”。只有此操作及重新提取会调用云端。
4. “完整题文”可看排版、编辑 Markdown＋LaTeX 源码、复制全文及恢复原文。
5. “条件与预览”核对角色、源码、所属小问及来源。悬停或聚焦条目高亮原图；点击来源区域定位条目。可禁用、删除、修改或重框来源。
6. 选择当前小问，只启用公共条件与其祖先条件；求解目标、选项不作已知。必要待确认条目和源码错误阻止导入。
7. 导入替换条件草稿，再由“放入绘图区 / 更新图形”提交主画布；取消不改主画布。

修改全文不会改动已确认条件。点击“按修订题文重新提取条件”后，先看差异，再确认替换。保存条件配置或最终绘图会保留题文、截图、来源与人工修改状态。

## 云端与数据保护

- Rust 调用百炼原生多模态接口：`qwen3.5-ocr` 的 `advanced_recognition` 提供实测文本区域；`qwen3-vl-plus` 非思考模式组织全文与条件。
- 只使用 `ocr_result.words_info` 的位置；忽略生成文本里可能出现的虚构坐标。定位只有整行时就高亮整行。
- 本地把独立复合条件拆开；保留原始源码，规范双重 LaTeX 转义与明确的数学等价写法。公式引入但未给定值的参数作为未知量，不能沿用普通画布自动补变量时的默认值 1。
- 不使用配图推断关系，不生成解答。模型可能遗漏、误读或使用不支持的语法，必须核对截图；有效 JSON 不等于数学正确。
- 不自动重试。取消会丢弃过期回复并阻止后续阶段；已经发出的 HTTP 请求可能继续在云端执行并计费。
- 图片数据 URI 最多 6 MiB；源图最多 8 MiB、1600 万像素、单边 12000；配置和绘图整体仍限制 8 MiB。超限提示裁剪，不静默丢来源。
- API Key 不返回前端，不写日志或绘图。设置在 Mathdraw 产品目录共享，旧隔离窗口设置自动迁移；macOS 钥匙串/Windows 凭据库使用 `lab.chuan.mathdraw.bailian / api-key`。
- 打开设置仅查询“是否已保存”的非密钥标记；首次识别读取密钥后在当前 Rust 进程内缓存，修改/移除密钥立即更新缓存。临时构建的签名变化后，macOS 第一次访问仍可能要求系统授权。
- Arrearage 为百炼余额/欠费状态；401/403 提示 Key、地域、模型权限；429 提示限流；超时或错误不修改主画布。

### 原题关系与求解器职责（本轮修正，优先于上面的早期记录）

此前把 `onBaseCircle` 编译出的等距、垂直关系放入识别条目，是错误的分层。用户明确要求：识别层只提交原题的几何关系，不能生成这些内部关系，不能仅用“隐藏”处理。

- `cone(O,D,A)` 声明直接提供底面圆 **O** 对象。圆用稳定 ID 管理，以 O 为圆心、OA 为半径、OD 为轴向；圆名和点名在各自引用上下文中解析。圆柱、圆台声明同样提供底面圆，圆柱顶面圆的半径沿用底面半径。
- “ABC 是底面的内接正三角形”直接提交 `onCurve(A B C,O)` 和 `regularPolygon(A,B,C)`，识别界面显示“点 A、B、C 在圆 O 上”“ABC 是正三角形”。不得改成 OB=OA、OB⊥OD 等输入。
- “AE 是圆 O 的直径”直接提交 `diameter(AE,O)`，不再提交改写后的中点条件。
- 一条圆上关系支持多个点（空格或逗号形式）。识别条目仅按原题关系分项，不按求解器编译结果拆项；正式条件的几何、代数及轨迹处理均在求解器内完成。
- 新增 `constraints/solidCurves.ts` 管理几何体提供的圆，`ConstraintCurve` 的可选 normalAxis/radiusSegment/solid 字段保存轴向与对象来源；求解器、解析表达、候选验证、输出场景共用真实圆对象。没有在识别层增加等距或垂直条件。
- 历史识别记录中由旧程序展开的条目，在重新打开识别窗口时根据原始关系和原文片段恢复；手工修改的条目保留。确认“导入并替换”后更新条件草稿，最终确认后才更新主画布。源码默认折叠，原题陈述保持可见。
- 本次仅追加一次圆锥题真实提取（复用 OCR），模型直接返回圆上关系和正三角形；四张题图真实响应回放通过。识别与约束模块共 237 项通过，覆盖任意方向的空间圆、圆柱顶面半径、直径及旧记录恢复。前端构建与 Mac Universal 完成，不升版本、不发布；Windows 未验证。
