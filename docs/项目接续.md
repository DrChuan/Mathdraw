## 2. 项目是什么

Mathdraw 是用于高中数学试卷、讲义和几何研究的 **macOS / Windows 本地桌面绘图程序**。

- React + TypeScript 界面，Tauri 2 + Rust 桌面外壳。
- 统一几何对象与依赖图；既可以点选作图，也可以输入表达式、方程和构造命令。
- 平面几何、圆锥曲线、空间几何、动态参数、轨迹、条件作图、SVG/PNG 输出。
- 正式应用运行于自己的窗口，使用内置打包资源；不要求用户开浏览器或启动本地服务。开发模式的 Vite 服务是另一回事。
- 起源于“枝间 / Mindgrove”笔记应用中的绘图窗口，后来增加独立启动配置；两者目前仍共用一个源工程。
- Mathdraw 绘图文件独立管理，不自动进入笔记库/COS 同步。

## 6. 开发时必须保持的约定

1. **通用修复，不给样例补隐藏条件。** “四棱锥”不意味着矩形底面；“棱柱”不意味着直棱柱。辅助构造可以隐藏，但数学条件不能偷偷增加。
2. 用户输入的普通长度/角等式是标量关系。`AB+BC=2AC` 不得自动当成向量式；向量应显式标记。
3. 构型自由度不计整体刚体平移/旋转；参照下可运动维数是另一个量。刚性形状换成单点参照不应虚报可变形。
4. 优先解析与精确计算，未覆盖时允许数值回退；没有找到不等于无解，小数残差通过不等于精确证明。
5. 自由点、派生点、条件体系中的点都服从同一套对象、样式、标签、依赖和显示规则。绑定点拖动必须满足整个条件体系，不能脱落成为普通自由点。
6. 保留对象稳定 ID。显示名、独立符号、ID、几何体的棱/面引用不是同一个概念。
7. 绘图区文字使用 Times New Roman：数字正体、数学字母斜体；保留燕尾箭头、统一线宽。中文工具栏使用界面字体。
8. 关闭、重启、更新应用前保护用户未保存的文件及表达式草稿。不要把用户窗口当一次性测试窗口；隔离检查使用不同应用标识。
9. 用户希望直接运行原启动器看到结果，不要每轮交付一个需要手动解压替换的 ZIP。
