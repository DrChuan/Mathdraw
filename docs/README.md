# 数学绘图 · Mathdraw

独立数学绘图程序、构建发布资料和说明书集中在本项目目录。

## 接续开发 / 开新对话

先读 **[项目接续指南](项目接续.md)**，其中包含当前版本与未发布源码的区别、关键路径，以及可直接贴到新对话的提示词。进一步查看 [开发文档索引](docs/README.md) 中的代码结构、求解器、构建发布和后续工作说明。

## 使用入口

- 双击本目录的 `启动数学绘图.command`（macOS）或 `启动数学绘图.cmd`（Windows）。
- 发布入口：`发布Mathdraw.command`。Windows 本机构建入口：`打包数学绘图Windows.cmd`。
- 发布包、历史版本和验证图保存在 `产物/`。说明书为 [MathDraw说明书.pdf](MathDraw说明书.pdf)。
- 绘图引擎与枝间笔记版共用，源代码在 [枝间/src/drawing](../枝间/src/drawing/)；Tauri 绘图配置及 Rust 源码在 [枝间/src-tauri](../枝间/src-tauri/)。
- 按条件作图的新声明与条件用法见 [曲线与度量说明](按条件作图-曲线与度量.md)。

旧入口已移除；请使用本项目目录中的启动器、`产物/` 和发布脚本。
