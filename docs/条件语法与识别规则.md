# 条件语法、识别协议与校验规则

核对日期：2026-10-25；源码版本 0.6.1（本轮未升版）。本页以当前解析器为准，不表示所有数学问题都能精确求解。

## 1. 三层职责

1. **识别**：抄录题文、拆分原文关系、给出对象定义和条件源码，并关联最短原文片段；只用题干，不从配图推断。
2. **编译和校验**：解析源码、检查对象/点引用、参数数量、模式及依赖，生成统一问题。失败条目不能导入。
3. **求解**：解释几何关系、生成内部辅助量、构造或数值计算，回代所有条件。求解器内部的等距、垂直和坐标方程不能回流成识别出的“原题条件”。

例如“ABC 是圆 O 的内接正三角形”对应 `onCurve(A B C,O)` 与 `regularPolygon(A,B,C)`，不能识别成一堆等长或垂直条件。“以 F_1F_2 为直径的圆”对应 `d=DiameterCircle(F_1,F_2)`；圆方程由对象编译层产生，不要求识别层先求中点或半径。

## 2. 名称、表达式和通用规则

- 模式：`coordinate` 平面有坐标；`plane` 平面无坐标；`spatial` 立体。后两者使用声明点与几何约束；有坐标模式另有对象定义和数值方程。
- 点先列入 points，空格分隔，例如 `P A B C A_1`。变量、曲线、命名直线不列入点名。点名必须以英文字母开头，后接字母、数字或下划线；避免与其他对象重名。
- 引用两个或更多点可紧写 `AB`、`ABC`；有歧义时用空格，如 `A_1 B_1`。平面通常用三个不共线顶点；四点以上平面关系由编译层检查共面并展开。
- 坐标对象使用稳定 ID，名称只用于输入与显示；重编译不应因修改题文而改变几何 ID。
- 数值支持整数、小数、分数 `1/2`、根式 `sqrt(3)` / `\sqrt{3}`、`pi` / `\pi`，数值函数完整列表为 `sin cos tan asin acos atan sqrt abs exp ln log log10 floor ceil sign min max`，其中 `ln` 与 `log` 都是自然对数。支持 LaTeX 分式、下标等；源码不含外层 `$`，可读文字才使用 `$…$`。
- 数值表达式支持 `+ - * / ^`、括号及隐式乘法；建议生成源码时显式写 `*`。不执行 JavaScript，不接受任意函数。
- 普通 `AB+BC=2AC` 是长度标量等式；只有显式 `vec(...)` 或 `\overrightarrow{...}` 才是向量。`dot(AB,AC)` 表示数量积，方向不能交换端点消掉。
- 角度默认度；`rad(pi/3)` 或含 `pi` 的数值表示弧度。三点角 `angle(A,B,C)` 的顶点是 B。线线角、线面角范围为 0～90°；三点角和二面角为 0～180°。正弦条件可能保留锐角/钝角两支。
- `AB=BC=2` 保留为一条原题关系，编译时展开；同一原文几何关系允许多行源码，不因内部编译拆成多条原文。
- 长度、面积、体积、半径必须正且有限；距离可为零。退化、初值不合法和语法错误是不同问题，不能以初值退化否定语法。
- 单条源码最多 2048 字符；问题最多 200 条条件或线段、通常最多 50 个声明点（有坐标对象上下文另有上限）；未知量最多 100 个。原图和完整配置仍受既有大小限制。

### 补充写法及语义

- 长度：`distance(A,B,3)` 或 `AB=3`；等长 `equal(AB,CD)`；长度比 `ratio(AB,CD,2)` 或 `AB/CD=2`。
- 定比分点：`division(M,AB,2)` 表示 AM:MB=2:1，且 M 在线段内；`midpoint(M,AB)` / `division(M,AB)` 默认 1:1。`onSegment(M,AB)` 仅限定在线段上。
- 共线 `collinear(A,B,C)`；共面 `coplanar(A,B,C,D)`（可多点）；平行/垂直允许线线、线面、面面，平面模式仅线线。
- 角：`lineAngle(AB,CD,60)`；`angle(A,B,C)=pi/3`；`linePlaneAngle(AB,CDE,30)`；`dihedral(BC,A,D)=60` 或 `dihedral(A,B,C,D)=60` 表示 A-BC-D。
- 三角函数：`sin(dihedral(BC,A,D))=sqrt(3)/2`、`cos(angle(A,B,C))=1/2`；`sinAcute`、`sinObtuse` 可明确分支。普通长度与角组合表达式如 `sin(angle(B,A,C))+sqrt(3)*cos(angle(B,A,C))=2` 也支持。
- 多边形必须按环绕顺序列点；相似/全等的两组点按对应顺序填写。`convexPolygon` 不增加等边、等角条件。`pyramid(P,A,B,C,D)` 不意味着矩形底面、正棱锥或直角侧棱。
- 棱柱/棱台先列底面点，再按对应顺序列顶面点；棱锥先顶点、再底面。圆柱/圆锥参数依次为底面圆心、轴向点、底面圆周点；圆台多一个顶面圆周点；球为球心、球上一点。
- 空间曲线：圆支持圆心＋圆周点、圆心＋半径、三点圆；椭圆为两焦点＋长轴长，需提供所在平面（圆锥等底面圆由几何体直接提供）。`onCurve(A B C,O)` 是同一条圆上关系。
- 圆锥声明 `cone(O,D,A)` 自动提供圆 O，`diameter(AE,O)` 保留“直径”关系，不能由识别层改成 `midpoint`。
- `volume(...)` 只支持棱柱、棱锥、棱台、圆柱、圆锥、圆台。`circumradius` 指三角形外接圆半径；`concyclic` / `cospherical` 可不指定半径。
- `onBaseCircle` 为旧配置兼容语法，识别新结果不得使用；其内部展开不是原题条目。

## 4. 有坐标模式的对象定义与关系

### 推荐识别词汇

|用途|写法|
|---|---|
|已知/未知坐标|`A=(2,0)`；`A=(?,?)`；也可只声明点名|
|已知/未知变量|`m=2`；`a=?`；范围另写 `a>0`|
|方程曲线|`C: x^2/a^2-y^2/b^2=1`；参数保留原表达式|
|命名直线方程|`直线 l: y=k*x+b` 或 `l: x=6`|
|过两点直线/线段/向量|`l=Line(A,B)`、`s=Segment(A,B)`、`h=Vector(A,B)`|
|焦点|`F_1=Focus(C,1)`、`F_2=Focus(C,2)`|
|主轴顶点|`A_1=Vertex(C,1)`、`A_2=Vertex(C,2)`|
|准线/渐近线|`l=Directrix(C,1)`、`l=Asymptote(C,1)`；第二条序号 2|
|圆心|`O=CircleCenter(c)`|
|圆|`c=Circle(O,A)`、`c=Circle(O,2)`、`c=Circle3(A,B,C)`|
|直径圆|`d=DiameterCircle(F_1,F_2)`（在条件对象编译层处理）|
|一对交点|`M,N=Intersect(c,l)`；构造不同的两个分支并检查互异|
|单交点|`M=Intersect(c,l,1)`；另一个 `N=Intersect(c,l,2)`|
|点在对象上|`onCurve(P,c)`、`onLine(P,l)`|
|待求交点|`intersection(P,c,l)`；两个待求交点须保留互异要求 `P!=Q`|
|关系|`parallel(l,s)`、`perpendicular(l,s)`、`tangent(l,c)`|
|命名直线夹角|`lineAngle(l,s,60)`（不是 `angle(l,s)=60`）|
|已存在点是特征点|`center(O,c)`、`focus(F,c,1)`、`directrix(l,c,1)`|
|坐标引用|`x(A)`、`y(A)`；如 `x(A)+x(B)=0`|
|曲线参数|`a(c)`、`b(c)`、`c(c)`（半焦距）、`e(c)`、`p(c)`、`radius(c)`、`eccentricity(c)`、`focalDistance(c)`（两焦点距离）|

构造序号从 **1** 开始。焦点和主轴顶点按左/下、右/上的顺序；一般旋转曲线的顺序按内核规则，不根据图上标签猜测。交点序号是几何分支序号，不等于题意中的左右/上下排序；必要时增加原题明确给出的范围。

直径圆是一般对象构造，保留两端点的动态引用；内部用 `(x-x(A))*(x-x(B))+(y-y(A))*(y-y(B))=0` 定义。这一处理发生在条件编译层，不作为新增的“识别条件”。

当构造在未知量初始值处不存在时，可改用原义的待求关系；不能代入一次数值采样的坐标让它“通过”。编译校验与可解性分开，含参初值退化不等于无解。

## 5. 识别条目和原文的对应规则

- `paragraphs` 是完整题文：合并自然排版换行，保留小问/选项/段落；不能作为每个条件的说明反复复制。
- `quote` 是单个关系的原文短语；`text` 是该关系的可读陈述；`source` 是实际可执行输入。这三者不能互相替代。
- 一个句子内有多个独立关系就按语义拆开；“分别”的成组定义可以作为一个关系包含多行源码；一个原文关系需要多个底层条件时，也可保留一条原文＋多行源码。
- 本地拆分只使用原文中真实存在的句读和短语；只有唯一对应时才自动关联。找不到独立片段时明确标“尚未可靠拆分”，整段原文集中展示一次，不给每条复制整句。
- 缩短 quote 不会把旧来源框冒充短语框；丢弃不再对应的模型框，回退 OCR 实测行框。OCR 整行定位和模型视觉估计必须区别标识。
- 条件卡并排显示“识别的原文片段”和“转换后的条件”；后者从实际源码重新解析生成，不照抄模型的说明。编辑源码后同步刷新。
- 同作用域、同角色的语义重复条件去重；保留不同小问、不同向量方向、不同标量表达式。不能因点名相同就合并不同关系。
- 目标、证明结论和选项只展示，不加入已知。公共条件归 common；小问启用自身及祖先，兄弟小问条件不能叠加。

## 6. 可用性检查与边界

1. 校验识别 JSON、图片尺寸、来源区域、稳定 ID、角色和小问树。
2. 规范明确的 LaTeX/转义/下标；保留原始输入记录。
3. 按依赖编译对象定义；按原题引用补全必要线段，不能把所有点两两连线。
4. 使用正式几何解析器校验几何条件；有坐标数值条件另做**不依赖初值**的语法、参数数量和引用校验。未知命令不能悄悄降级成一个数值方程。
5. 条目错误就标明并禁用导入；无错误只表示能进入求解器，不表示数学条件完整、可解或能精确求解。
6. 自动预览求解后回代；当前条件未满足时保留上一次有效图形并禁止最终提交。不能用“语法通过”代替“已满足”。

代码入口：`recognition/grammar.ts`、`recognition/model.ts`、`recognition/review.ts`、`constraints/catalog.ts`、`constraints/input.ts`、`constraints/planarLesson.ts`、`constraints/planarSyntax.ts`、`constraints/planarExpressions.ts`。识别工作区只在用户主动识别/重新提取时调用云端，不循环重试。

## 7. 本轮双曲线题的原义构造链

题干截到了“则”，没有给出后续问题，不能补写目标或选项。

```text
a=?
b=?
C: x^2/a^2-y^2/b^2=1
a>0
b>0
F_1=Focus(C,1)
F_2=Focus(C,2)
A_1=Vertex(C,1)
A_2=Vertex(C,2)
d=DiameterCircle(F_1,F_2)
l=Asymptote(C,1)
M,N=Intersect(d,l)
angle(N,A_1,M)=5*pi/6
```

这里的渐近线序号只选原题“一条渐近线”的一个分支；另一条也存在。不得额外填入双曲线参数的解、强设尺度或给定顶点坐标。若用户要遍历镜像分支，应由构型/分支机制处理，不能伪造原题条件。

## 8. 三种识别入口

- **仅识别文本**：只调用 OCR，返回可编辑、可复制的文字＋LaTeX；没有条件，不可直接导入。
- **截图识别到条件**：OCR 后先保留题文，再请求条件；条件格式错误或提取失败时题文仍在。
- **当前文本提取条件**：不重新 OCR，以当前文本框为准；截图仅辅助寻找来源，不能覆盖文本中的人工修订。已有条件时先确认替换差异。

响应的缺失来源字段在后处理之前校验；缺失来源不产生猜测位置。文本入口的必要条目必须有能在当前题文中找到的原文引用；只有题文且没有条件的草稿不可导入。

## 9. 图形构造式引用

条件的点组引用支持 `Point(A)`、`Segment(A,B)`、`Line(A,B)`、`Vector(A,B)`、`Triangle(A,B,C)`、`Polygon(A,B,C,D)`、`Plane(A,B,C)`，按类型校验顶点数量，不会创建第二份对象。例如：

```text
area(Triangle(O,A,B))=sqrt(2)
area(Polygon(A,B,C,D))=6
circumradius(Triangle(A,B,C))=2
perpendicular(Line(A,B),Plane(C,D,E))
```

与直接引用对应顶点含义相同。非法顶点数或不支持的图形引用在几何解析层报错，不回退成数值函数再报告函数名中的某个字母有误。

## 10. 辅助数值参数的本地名称分配

API 返回后自动检查辅助参数占用。例如椭圆半轴为 b，直线辅助截距也用了 b，则后者改为 b_1，原题半轴不改。同步更新数值引用，按原文条目及小问作用域处理，兄弟小问隔离。点、对象引用与坐标轴不因数值同名而改写。保留原始源码与改名说明；明确原题符号和人工编辑优先，无法判断的语义不靠全局字符串替换猜测。

## 11. 2026-10-25 全链路语法审计与命名关系协议

### 11.1 不可混用的三个输入类别

|类别|输入|解释|
|---|---|---|
|点组几何条件|`angle(A,B,C)=60`、`angle(AB,CD)=60`|参数是声明点或由点组成的引用，不能直接塞命名直线 l|
|命名对象关系|`lineAngle(l,s,60)`、`perpendicular(l,AB)`|解析对象名或两点直线引用；数值在最后的参数中|
|对象定义|`l=Line(A,B)`、`l: y=k*x+b`|生成对象；不能拿关系函数作对象构造|

尤其不能写 `angle(l,x_axis)=30`：`x_axis` 不是内置对象，`angle` 的点组签名也不接收命名直线。**直线倾斜角用 `inclination(l,30)`**，表示从 x 轴正向逆时针转到直线的角，取值 `[0,180°)`。150° 与 30° 不同；90° 支持竖直线。`lineAngle(l,s,30)` 则是两条无限直线的较小夹角，取值 `[0,90°]`，不能替代倾斜角。弧度写 `inclination(l,pi/6)` 或 `inclination(l,rad(pi/6))`。

示例（保持原题给定角度，不在识别层计算斜率）：

```text
k=?
l: y=k*(x-x(F_2))+y(F_2)
inclination(l,30)
```

若原题角度为90°，直线定义不能使用有限斜率模板，应直接使用 `l: x=x(F_2)` 或一般式。需要保留可变方向时，`l=过点直线(F_2)` 是现有输入模板，其内部引入方向参数；识别层不填入求得的斜率。

### 11.2 命名关系的准确参数表

该表对应 `constraints/planarRelations.ts`，提示词、参数数量检查和求值分派共用同一目录。有坐标模式使用这些关系；点组几何条件继续以第3节目录为准。

|规范写法|参数含义|
|---|---|
|`pointLineDistance(P,l,2)`|点、直线、距离|
|`onCurve(P,c)` / `onLine(P,l)`|点（或空格分隔点组）、曲线/直线|
|`intersection(P,c,l)`|点、对象1、对象2|
|`tangent(l,c)`|直线、二次曲线|
|`parallel(l,s)` / `perpendicular(l,s)`|两条直线；也可引用 AB 端点组|
|`center(O,c)`|中心点、曲线|
|`focus(F,c,1)`|焦点、曲线、可省略的1或2序号|
|`directrix(l,c,1)`|直线、曲线、可省略的1或2序号|
|`lineAngle(l,s,60)`|两直线、较小夹角|
|`inclination(l,30)`|直线、倾斜角|
|`distance(s,2)`|命名线段/向量、长度|
|`equal(s,t)` / `ratio(s,t,2)`|两线段/向量、可选比例（ratio必需）|
|`vectorDot(h,j,2)`|两向量、数量积|

点组签名 `distance(A,B,3)`、`pointLineDistance(P,AB)=2` 属于几何条件解析器；命名关系采用上表签名，不能把 l 当作点或混用括号外等号。数值参数中的括号、嵌套函数逗号应按层级切分。

### 11.3 名称与模式

`x,y,u,v` 是表达式坐标保留符号，不用作对象名。独立数值变量还须避开 `z`、`pi` 与内置函数名。`e` 未声明时是自然常数；原题明确给出或曲线表单明确创建离心率参数时可显式绑定 `e`，辅助参数不要占用它。命名向量可用 h、j，不能用 v。API返回后只对可确定的辅助数值绑定做局部改名；无法确定含义的冲突仍须用户核对。

平面两模式禁止体积、点面距离、线面角、二面角、共面、共球及空间几何体；无坐标模式曲线限圆。坐标模式允许对象方程、参数、坐标引用。立体模式不接收平面坐标对象定义。各模式的语法和求解能力不能混为一谈。

### 11.4 本地检查流程

1. 响应结构和来源检查，保留原始题文与源码；只做明确的格式规范与辅助变量避让。
2. 按作用域逐个构建问题，公共与祖先条件继承，兄弟小问隔离。
3. 正式对象编译、几何解析及坐标关系检查：名称、类型、参数数量、模式、依赖、常量角度范围；错误定位到原识别条目。
4. 全部小问预检；未选中的小问也不能藏着语法错误。错误条目保留并阻止导入，不悄悄删除，不自动付费重试。
5. 可执行问题才交自动预览与原始条件回代。语法检查不等于语义忠实度证明，也不等于已求得有效构型；初值退化不作为语法错误。

### 11.5 可重复的协议检查

`recognition/grammar.test.ts` 自动枚举几何目录全部示例和命名关系签名，另覆盖主要对象构造、错误参数/名称、倾斜角方向及单位、截图中“过焦点直线+倾斜角”的编译到求解，以及非当前小问的错误。不能只断言提示词含有命令名称：必须经过正式解析器，关键例子还须求解回代。

本轮审计还发现并修正：`Circle3` 的命令名含数字，原录入分类漏识别；多行源码中 `M,N=Intersect(...)` 的逗号可能被错拆成两个条目；命名关系引用 AB 时语法允许但求值未解析端点。上述均增加回归覆盖。

此检查不能保证云模型永不误读原题。未做真实云端复测时必须单独说明；模拟响应、历史真实响应回放、当前模型调用和实际图形求解不是同一层验收。
