# 平面条件作图

平面画布的“按条件作图”提供有坐标、无坐标两套独立草稿；立体画布继续打开原来的空间工具。

## 有坐标

当前画布全部对象进入同一对象列表，保留 ID、样式、隐藏状态和构造关系。原坐标、数值和方程是已知条件；在对象行勾选独立坐标或数值的“待求”即可反求。派生点通过来源计算，不改成自由点。重新打开时会合并已有平面条件体系，避免嵌套一份固定快照。

新增定义支持 `A=(1,2)`、`A=(?,?)`、`a=?`、`c: x^2/a^2+y^2/b^2=1`。条件支持原几何简写、坐标表达式 `x(A)` / `y(A)`、长度代数式、带数值系数的显式向量关系及范围不等式。

坐标与圆锥曲线条件的完整输入提供点在图形上、交点、相切、中心、焦点、准线、半轴、离心率、焦距、抛物线参数和圆半径。直线或线段也可按对象名引用。

例如先建立 `a=4`、`b=2`、`A=(3,0)`、`B=(0,2)`、`c: x^2/a^2+y^2/b^2=1`，将 a、b 标为待求，再添加 `onCurve(A,c)`、`onCurve(B,c)`、`a>0`、`b>0`，可消元得到 a=3、b=2。

## 无坐标

独立声明点、线段、平面图形和圆，不导入当前画布。圆支持圆心与圆上一点、圆心与半径、三点圆，无需额外声明三个平面点。此模式的构型自由度排除整体平移和旋转；当前参照下的可运动维数单独显示。镜像分支保留。

## 求解与数据保护

- 优先几何构造、有理表达式消元和精确实根隔离；能证明的分数、根式或代数根保留相应表达。
- 二次曲线求交不受视窗范围限制；用户明确设置的曲线范围、线段/射线边界会参与验证。
- 复杂系统超出当前解析规则时允许数值联立，明确标注近似原因。独立待求量需要上下界；新声明点的数值搜索框可在“近似搜索范围”设置。无坐标模式提供搜索尺度。搜索范围本身不成为几何条件。
- 参数曲线等已有对象及其原生依赖会保留；暂不支持直接以其占位隐式方程进行求交，会提示使用参数定义点。
- 求解在可取消 Worker 中运行；每个候选、动点拖动及参数滑块更新均回代条件。无效位置不发布。当前最多同时处理 100 个独立待求坐标分量或参数。
- 确认前不改变主画布；确认作为一次撤销操作，画布已变化时拒绝旧预览覆盖。配置重名会提示，可在定义列表重命名后合并。
- 绘图格式 v4、条件配置 v2。兼容读取旧文件；旧绘图首次保存另存，保留原文件。旧版应用不能读取 v4。

本轮不提升应用版本、不上传发布；使用发布入口时仍按现有流程选择版本号。
