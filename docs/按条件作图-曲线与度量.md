# 曲线、面积、体积与共圆共球条件

## 声明曲线

在“按条件作图 → 声明与条件”中先声明点，然后在“曲线”列表点击“添加曲线”。

- 圆：圆心与圆上一点、圆心与半径、三点圆。
- 椭圆：两个焦点与长轴**全长** 2a；全长必须大于两焦点的距离。
- 除三点圆外，需要指定三个点表示所在平面，从而确定空间朝向。定义圆的点、椭圆焦点须在此平面中。
- 半径及长轴长支持分数、根式和 π。曲线与其定义点关联，配置保存包含曲线列表。

“位置关系 → 点在曲线上”可给声明的点添加关联，简写为 `onCurve(P,c)`。

## 声明曲面几何体

“声明图形”中新增以下类型，选择后为特征点命名。圆柱、圆锥、圆台是直圆几何体。

| 类型 | 简写与定义点 |
| --- | --- |
| 圆柱 | `cylinder(O,O_1,A)`：下、上底圆心及下底圆上一点 |
| 圆锥 | `cone(O,P,A)`：底面圆心、顶点及底面圆上一点 |
| 圆台 | `coneFrustum(O,O_1,A,B)`：下、上底圆心及各自圆上一点；两半径方向对应 |
| 球 | `sphere(O,A)`：球心与球上一点 |

用长度条件指定半径和高度，例如 `OA=2`、`OO_1=3`。生成后得到带遮挡线的曲面几何体。

## 面积与体积

完整输入新增“面积 / 体积”分类。多边形顶点按边界环绕顺序填写，可以是简单凹多边形，不能自相交。体积可直接选入已声明的几何体。

```text
area(ABCD)=6
volume(prism(A,B,C,A_1,B_1,C_1))=12
volume(pyramid(P,A,B,C,D))=4
volume(frustum(A,B,C,A_1,B_1,C_1))=7
volume(cylinder(O,O_1,A))=12*pi
volume(cone(O,P,A))=4*pi
volume(coneFrustum(O,O_1,A,B))=7*pi
```

体积支持棱柱、棱锥、棱台、圆柱、圆锥、圆台；正方体可按棱柱填写。球体积本轮不包括在内。

## 外接半径与共圆共球

在“长度”分类选择以下条件。共圆、共球的半径可以留空。

```text
circumradius(ABC)=sqrt(3)
concyclic(A,B,C,D)
concyclic(A,B,C,D)=2
cospherical(A,B,C,D,E)
cospherical(A,B,C,D,E)=3
```

三角形外接圆需要三个不共线点；共圆至少三个点，共球至少四个点。共球条件判断是否存在这样的球，不要求球心唯一；例如共面的共圆点，可以存在多个满足指定半径的球。直接创建“外接球”的工具仍要求能唯一确定球。

求解仍优先使用几何构造与轨迹求交；新增面积、半径的边长推导、圆面及球面求交、圆柱圆锥圆台的半径高度构造。未能直接构造的组合保留数值求解及回代校验，求解方式会显示在结果页。
