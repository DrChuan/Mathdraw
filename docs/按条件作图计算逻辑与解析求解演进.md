# MathDraw 按条件作图：计算逻辑与解析求解演进

整理日期：2026-10-23。本文以当前工作区源码为准，不代表已发布安装包的行为。此次只新增本文档，不修改实现。

## 1. 结论与开发目标

当前系统是“几何构造优先、部分有理代数消元、数值联立兜底”的混合求解器，尚不是统一的精确符号求解器。空间和二维走不同分支，能力不完全对齐。

建议把后续目标具体化为：尽量将几何条件转为精确的代数或半代数问题；有限解输出可验证的代数数，连续解输出带有效域的参数族或隐式关系；无法完成时明确返回未完成的原因，数值结果仅作为显式标注的预览。不要把“所有输入都必须输出有限根式坐标”作为接口承诺。

需要分开记录以下四件事：

| 维度 | 当前含义或问题 | 建议目标 |
| --- | --- | --- |
| 求解方法 | construction / hybrid / numerical | 保留方法与推导步骤 |
| 表示精度 | construction / algebraic / approximate，空间路径常未设置 | 区分精确表达、认证代数根、认证区间和普通近似 |
| 解集完整性 | complete 一个布尔值 | 区分有限解穷尽、连续族覆盖、尚未完成、截断 |
| 有效性证明 | 大部分靠浮点回代 | 保存可独立复核的等式、非零与符号证据 |

使用几何公式不等于符号精确；获得一个合格构型不等于枚举全部解；保留代数根定义也不等于原始条件已被精确证明。

## 3. 输入、执行和落盘

`ConstraintProblem` 保存点、显示线段、启用条件、声明曲线和模式。显示线段不自动等同于长度约束。模式为 spatial / plane / coordinate，未指定时走空间路径。

`Condition` 保存结构化类型、点引用、数值及原始 source。部分三角条件还有 alternateValue。多数几何条件的 value 和 coefficients 已是 JavaScript number，保留 source 并不意味着后续一直使用精确值。

二维 `PlanarContext` 额外保存原 DrawingDocument、待求字段、附加方程、搜索范围及吸收的已有条件集。已知对象由原定义求值；被选为待求的字段才成为变量，新声明点贡献 x、y 两个变量。依赖对象在每次候选回代时重新求值，不能把随未知量变化的对象冻结为当前坐标。

界面首次预算 2000ms，继续计算 8000ms。请求进入 Worker，求解器内部通常将预算限制在 30～10000ms。外层另有“请求预算 + 2500ms”超时保护；取消会终止 Worker。现有预算同时承担交互响应与数学计算的限制，耗时不足不意味着无解。

结果为若干 SolutionBranch：坐标、参数值、固定参照、刚性块、自由度、轨迹和残差，二维可附 exactValues。安装前 `validateSolutionSet` 再次回代；有坐标模式会将结果安装回原对象体系。当前落盘验证主要验证数值构型，并未验证完整的代数证书。

## 4. 空间模式实际计算顺序

### 4.1 前处理与特殊请求

1. 校验问题；若只是刷新自由度，则使用旧坐标重新分析。
2. 处理含 alternateValue 的条件。初次求解最多枚举 64 种角度组合；超过六项多值条件的全部组合不会展开，完整性相应不能保证。
3. `contradictions` 检查已有规则能识别的明显冲突。这是局部规则检查，不是通用不可满足性判定。
4. 固定参照请求只改变固定点与运动分析，不放松条件。
5. 拖动请求进入单独的联动流程，见第 7 节。

### 4.2 特定直棱柱快速构造

`constructRightPrism` 成功时：按相邻边及夹角推导底面距离，圆交点枚举底面，排除自交，再沿法向正负平移生成顶面，回代原条件。

构型消去整体平移与旋转；保留镜像候选。返回最多 12 个构型，标记 construction。此路径的坐标与三角函数运算仍是浮点计算。

### 4.3 通用构造规划

`planConstructions` 先调用 `expandConditions` 和 `metricNetworks`：

- 展开平行四边形、棱柱等图形的向量或几何关系。
- 传播已知长度、等长、比例、相似对应边及棱柱对应边。
- 两边夹角用余弦定理推导第三边，无向线线角保留两种余弦符号。
- 部分面积、体积、外接半径及点积条件可进一步推导尺寸。

放置初始框架后逐轮处理未知点，优先传播向量线性关系、定比分点、平行四边形与棱柱平移、棱台位似关系。其余点尝试转为轨迹：

| 条件 | 常见构造对象 |
| --- | --- |
| 到已知点的距离 | 球面；平面问题再附 z=0 平面 |
| 等距 / 定距离比 | 垂直平分面 / 阿波罗尼斯球面 |
| 共线 / 线段关联 | 两辅助平面的交线，线段范围在回代时检查 |
| 共面、部分平行垂直与点积 | 平面或球面 |
| 已知圆上的点、共圆共球 | 圆对应球面加平面，或球面 |
| 部分角度、线面角、二面角、棱锥体积 | 一个或多个辅助平面 / 球面 |

球面相减消去平方项得到根平面；联立平面做线性消元，再与球面求交。候选可为有限点，也可为直线、圆、平面、球面等连续对象。规划器优先选择维度较低的点轨迹，部分整体旋转自由可作为坐标规范消去。

每个部分候选和最终候选都回代可检查的条件，拒绝退化、自交和范围错误。规划最多保留 16 个状态 / 候选，并记录时间或候选截断。未能继续构造的部分坐标作为 seeds。

若规划得到解且没有旧分支，空间求解器可直接返回 construction；有限规划固定全部点，连续规划再分析自由度和轨迹。注意，“连续规划得到几个代表构型”不是完整参数解集。

### 4.4 数值回退

无法直接返回构造解时，最多做 32 次多起点搜索：使用部分构造种子、随机初值、旧分支镜像或扰动，执行阻尼最小二乘。Jacobian 为数值差分；接受与否由原条件回代决定。

数值结果最多 12 个分支，complete=false；没找到解为 notFound。若有较完整的构造种子则标 hybrid，否则 numerical。“继续求解”传入旧分支时，即使本轮构造得到候选，也不会走上述首次求解的直接返回判断。

## 5. 平面与有坐标模式实际计算顺序

二维在总入口直接转到 `solvePlanar`，不经过空间主流程的多值角展开和矛盾预检。几何残差仍复用 compile；所有候选还要检查原对象定义、二维平面深度、表达式条件及变量范围。

### 5.1 解析尝试的顺序

1. 没有未知量：直接验证已有定义与条件。
2. 有 PlanarContext、1～2 个独立变量及启用附加方程：尝试 `symbolicPlanarEquations`。
3. 一元：逐条尝试可转为有理多项式的等式，隔离该式全部实根，再回代所有条件。首条成功隔离的等式就是候选全集的来源。
4. 二元：选取方程对，计算两个方向的 Sylvester 结式；分别隔离投影坐标实根，做笛卡尔积并回代筛选。
5. 尚未成功、无原对象待求字段、只有一个新点：识别 onCurve / onLine / intersection，尝试两条既有直线或二次曲线求交。
6. 尚未成功、没有原对象待求字段且没有附加方程：调用通用几何规划器。
7. 以上均未成功才进入限定范围的数值搜索。

这里“变量数”统计独立字段和新点坐标，而非界面点数。一个新点通常已有两个变量，两个新点通常就超出当前代数路径的入口限制。结构化 conditions 也没有统一进入代数消元；symbolicPlanarEquations 的主要输入是 context.equations。

### 5.2 当前符号翻译覆盖

支持部分数值对象依赖替换、x(P) / y(P)、自由点、别名点、定比分点、直线、若干圆和未旋转的预设二次曲线。

未知量相关但未支持符号翻译的构造会退出符号尝试；内切圆、旋转预设曲线及若干 tangent / focus / directrix / center 等条件未形成统一代数方程。部分不支持的附加条件会被略过生成阶段，但仍参与最终回代。

这种做法在“候选来源确实包含全部解”的前提下可以工作，关键是不能把未翻译条件当作已经精确处理，不能把具有连续解的候选来源误当有限全集。

### 5.3 algebraic.ts 的精确能力与限制

一元核心使用 BigInt 有理系数：清分母、移除与分母共有的根、去重因子、构造 Sturm 序列、隔离实根。输出整数多项式、隔离区间、近似坐标及可选表达式。一次式可给分数、二次式可给根式；更高次数可仅用“多项式 + 隔离区间”表示。

当前限制包括：拒绝一般函数调用和 π / 三角 / 指数 / 对数；一元输入整数幂绝对值最多 8，最终多项式次数最多 9，求根界不超过 1e9，并有时间和隔离队列限制。限制触发通常返回 undefined，表示没有完成该方法。

二元内部限制总次数、幂次和 Sylvester 矩阵大小（最大 6），并受一元求根限制。两投影坐标组合后，分母非零与等式成立的判定仍使用 number 和误差阈值，不是精确的二元代数点认证。

系数来自已解析的 number 再转有理数；因此“精确”首先是针对转换后的有理模型。原始十进制词法、根式、常数及构造依赖的精确语义尚未完整贯通。隔离区间最终也保存为 number 端点。

### 5.4 二维数值回退

最多 100 个独立变量，最多 24 次起点，每次最多 100 次阻尼迭代，最多展示 12 个分支。待求参数必须显式设置上下界；有坐标新点的每个坐标必须提供搜索上下界。无坐标点允许使用 searchScale（默认 20）乘问题尺度作为初始搜索盒。

视口不作为数学定义域。候选需要回代：结构化几何条件、原对象求值错误、平面深度、表达式条件和变量上下界。数值失败返回 notFound，不应解释为数学无解。

无坐标二维构型会移到首点原点并旋转到第二个非重合点方向；注释要求保留镜像。连续解目前仍保存若干坐标样本，通过距离阈值去重。

## 6. 有效性、自由度、分支与轨迹

compile 的空间有效性要求坐标有限且绝对值不超过 1e9，归一化条件误差小于 3e-6，并通过退化与底面自交检查。二维附加方程也有相近容差，并单独调用 satisfied 检查严格不等式等语义。

空间刚性块来自 Jacobian 行空间、点间距离梯度及扰动样本；localMobility 再分析局部可动性，处理部分一阶零方向被高阶条件锁住的问题。二维自由度主要由数值 Jacobian 秩估计，无坐标模式扣除平面欧氏运动维数；motionDof 另外加入固定参照。

这些是局部分析，不能证明全局解集维数、连通性或所有分支。空间去重依赖刚性块距离与手性，二维依赖坐标 / 参数距离阈值；都可能合并非常接近的离散根，也不能认证连续族的连通分量。

解析轨迹支持线、线段、圆、平面、球面；空间某些一维联动还会通过切向预测与数值校正生成 sampled 路径，明确 complete=false。点轨迹完整性与整组构型解集完整性应分别记录。

## 7. 拖动和参数改变

空间拖动顺序：固定参照校验 → 投影到已有轨迹 → 尝试刚体运动 → 以参照和目标点为锚重新规划从动点 → 选择接近旧构型的候选 → 必要时数值联动 → 回代全部条件。

二维拖动先投影到已知轨迹，再数值联立固定参照、目标点和原条件。若目标不能达到，可能退回满足硬条件的位置，因此拖动后构型可行不代表鼠标目标可达。

二维参数改变先直接替换候选值，必要时数值校正，并检查目标参数值是否实际达到。两类二维操作最终标为 approximate / hybrid。

后续要让交互也尽量保持解析，应复用符号构造图或代数分支，而非每次丢弃关系重新优化。鼠标坐标可以作为近似输入，但其派生关系仍可保持精确的参数表达。

## 8. 当前问题与建议验证用例

以下区分源码已确认的限制与需要进一步复现的风险；本次没有修改实现，也没有新增测试来宣称这些风险已被复现。

| 优先级 | 发现及依据 | 影响 / 建议验证 |
| --- | --- | --- |
| P0 | 二元 algebraicSystem 用近似坐标检查 abs(n/d)<1e-6、abs(d)>1e-10 | 很接近的错误配对可能被接受，极小非零分母可能被排除；用近邻根、近极点和大系数用例验证。引入精确代数点与符号判定 |
| P0 | 一元 / 二元候选回代后可直接设置 complete=true、零候选可报 contradiction | 候选隔离的精确性不能替代全部原条件的精确筛选；特别检查严格不等式边界、含根式已知对象和尺度悬殊条件 |
| P0 | 二维 conicIntersections 走浮点根隔离、Newton 修正与容差去重，但外层设 analytic=true、complete=true | 相切、近重合、近邻交点需要检查完整性证据；该路径不能等同认证代数求解 |
| P0 | 二维 accept 的分支去重使用 scale*1e-5 与参数 1e-6 阈值 | 不同离散根可能合并后仍声明 complete；用间距小于阈值的两根验证，改用代数根身份 |
| P0 | 二维 request.move / parameter 复制旧结果、替换一个分支，但没有重算 complete，参考切换 make 也未携带 exactValues | 旧精确值可能被丢弃，旧完整性可能被错误沿用；多根方程拖动 / 调参后检查分支、证书和状态一致性 |
| P0 | validateSolutionSet 没有校验 exactValues 的多项式、区间与坐标对应，也未完整约束 precision | 精确标签缺少落盘验证；添加损坏证书和坐标与根不一致的保存恢复用例 |
| P1 | 符号入口仅 1～2 个变量，且未统一编译结构化 conditions | 很多本可消元的问题直接数值回退；以多个点但可线性消去大多数坐标的题目验证 |
| P1 | 规划器逐点贪心选择维度最低的轨迹，连续轨迹主要取代表点 | 循环耦合与后续约束可能需要“先保留参数再求解”；改为求解剩余耦合块，避免盲目增加采样 |
| P1 | plane 在总入口提前分流，未执行空间 alternateValue 组合展开 | 检查无坐标平面 sin(vertexAngle)=1/2 是否保留两种顶角；需统一多值语义再进入求解后端 |
| P1 | 二维自由度主要依赖 Jacobian 秩，空间还有高阶局部分析 | 检查 m^2=0、相切、极值处是否显示伪自由度；维数声明需要额外依据 |
| P1 | 空间拖动数值回退更新 method，但空间通常无统一 precision；二维精确元数据生命周期也不完整 | 精度应按分支及操作跟踪，数值校正必须使相关证书失效 |
| P2 | 超时、次数上限、不支持表达式常统一返回 undefined | 用户和开发者难以判断为何没有解析解；返回结构化失败原因和未求解块 |

另外，解析完成后展示上限与计算上限应分离。目前多处使用 12 / 16 的上限，后续增加消元覆盖时要保证“只展示前 12 个”不会影响完整解集证书。

## 9. 建议架构：几何化简与精确代数共用中间层

### 9.1 保留精确输入与数学语义

引入可序列化的精确表达式树：整数、有理数、命名常数、代数根、运算节点。输入十进制从原始字面量转为有理数；分数和根式从解析开始保留结构。number 作为渲染缓存，而不是唯一事实来源。

Condition.value 不宜单独承担精确语义；结构化输入与 source 应由同一表达式模型生成，避免两份定义漂移。对 π、固定角与一般超越表达式，必须明确常数域和后端能力。

### 9.2 编译为“等式 + 不等式 + 非零条件”

统一编译二维和空间的条件与原对象依赖。距离使用平方距离；平行垂直使用叉积 / 点积；共面用行列式；线段用参数 t 及 0≤t≤1。圆锥曲线、向量线性关系等也进入同一层。

平方、清分母和消去绝对值时必须记录伴随条件：长度非负、分母非零、角度方向 / 象限、法向非零、正负体积及非退化。不能只留下消元多项式，否则会引入增根或删除合法分支。

一般角度关系可引入辅助长度变量，平方后保留符号条件。面积、体积先明确有向 / 无向语义。固定特殊角可使用其精确三角值；一般三角参数保持符号条件或明确超出代数后端范围。

### 9.3 先降维，再按耦合块选择后端

1. 精确线性消元：定比分点、向量关系、平行四边形、棱柱平移、已知坐标，优先消去从属点。
2. 构造表达式图：距离传播、圆球求交等生成表达式与分支条件，避免立刻转浮点。
3. 分析变量—条件图，拆独立分量和耦合块；每个块输出有限解、参数族或未完成关系。
4. 对低维块使用一元隔离、结式、三角分解等后端；再评估是否需要 Gröbner 基或实代数分解。不要直接把全部空间坐标放进大规模符号消元。
5. 将各块结果组合，并复核原始条件。预算耗尽保留可继续计算的任务状态，而非只保留坐标起点。

### 9.4 有限解与连续解分别表示

有限解建议用共同代数生成元及各坐标表达式，或带相容性证据的代数坐标元组；不能仅用两个独立坐标根的笛卡尔积加浮点过滤。

连续解应输出自由参数、参数域、各点表达式和离散分支条件。不能全局参数化时，可输出隐式关系或多个局部图表。分母为零、相切、共线等特例应作为独立分支处理，不能在一般式推导中直接丢弃。

表达式复杂并不构成转数值的理由；可以保留“多项式某个隔离实根”或隐式族。没有有限候选时，也不应为了给出坐标而任取几个样本并称作完整解。

### 9.5 证书、显示与交互分离

结果应按分支保存推导、域条件、精确根身份及原条件验证状态；整体保存覆盖范围和未完成部分。用有理端点表示隔离区间，允许按需提高精度。显示可以给小数或简化根式，但不能用小数反猜根式作为证明。

拖动复用表达式图与分支身份，依据连续性跟踪同一分支；到奇异点允许显式分裂或切换。数值预测可以辅助定位，但不承担精确性认证。导入、保存、恢复时验证证书与输入版本及当前参数是否一致。

## 10. 建议开发顺序与验收

| 阶段 | 重点 | 验收依据 |
| --- | --- | --- |
| 第一阶段 | 修正精度 / complete / exactValues 生命周期，完善失败原因和证书校验 | 数值更新不沿用旧证书；未认证结果不宣称穷尽或证明无解 |
| 第二阶段 | 精确常量、有理端点、统一线性消元，扩大符号翻译 | 线性关系先消元后变量数明显减少；有坐标与无坐标同义题结果一致 |
| 第三阶段 | 精确圆球构造与二元代数点认证 | 相切、重根、近极点、近邻根均可验证；分支不依赖容差去重 |
| 第四阶段 | 耦合块消元、连续参数族、空间代数后端 | 循环耦合题不再仅靠随机初值；有限解和连续族分别完整表达 |
| 第五阶段 | 复杂退化分层、超出代数范围的表达式与后台长计算 | 特例有独立分支；超时可恢复；明确说明能力边界 |

解析覆盖率建议按题型统计，不以“本次找到合格浮点点”的数量衡量。至少记录：精确有限解覆盖率、精确参数族覆盖率、认证无解比例、未完成原因、降维后的块规模、证明与显示耗时。

建议测试矩阵包括：

- 线性系统：唯一解、无解、冗余条件、自由参数与点名 / 条件顺序变化。
- 代数根：有理根、根式根、无简单根式的实根、重根、近邻根、多项式次数边界。
- 定义域：清分母增根、分母为零分支、严格不等式边界、线段端点与曲线范围。
- 几何分支：镜像、无向角两值、相切、重合、共线共面及自交排除。
- 空间耦合：斜棱柱、共享顶点、多个未知点循环关联、面积体积条件。
- 交互与持久化：拖动 / 调参 / 换参照 / 保存恢复后的精度、根身份和完整性一致。
- 运行限制：超时、候选截断、巨大 / 微小尺度，区分未找到与证明无解。
