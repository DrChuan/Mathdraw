# 空间工具更新（0.2.4）

## 建立坐标系

沿用“原点 → x 正方向 → xOy 面 → y 正方向 → z 正反”的步骤。点击已有直线或棱的中部时，优先复用该线上离点击位置最近的已有点；已选择的点不会再次作为方向点。按 Alt 可临时关闭吸附。

选用其他点作为原点后，初始 O 不再显示，也不再自动补回。若已有图形引用了原来的 O，内部保留一个隐藏辅助点以维持图形；无引用时移除。

## 向量与法向量

向量在左侧对象列表显示坐标。立体工具中的“法向量”可点击多边形、三角形或几何体的平面面；选中多边形后也可使用快捷操作。

定义示例：

```
vec = Vector(A,B)
n = Normal(A,B,C)
n = Normal(p)
n = Normal()
```

最后一种取当前工作平面的法向量。构造与来源关联，来源退化时暂停显示，恢复后继续计算。

固定法向量会约去公因子、消去公分母，并处理常用二次根式，例如 `(1,sqrt(3),2)`。普通参数点、坐标引用、等分点、重心、棱柱及棱锥的顶点等来源会保留参数表达式；较复杂、暂不能符号展开的来源仍实时更新数值，并标明参数依赖。当前不是通用计算机代数系统，复杂代数常量可能显示近似值。

## 截面

在“立体工具 → 截面”中选择“三点 / 两直线 / 直线＋点”。先选择几何体，再依提示选择截平面的来源。

```
p = Section(S,A,B,C)
p = Section(S,l1,l2)
p = Section(S,l,A)
```

可以选择几何体的棱及棱上的新点。截面随来源变化，能作为工作平面、法向量和面积/周长度量的来源。异面直线、三点共线、相离或仅相切时给出原因；来源恢复有效后重新显示。新建构造作为一次操作撤销。

多面体按实际三角面求交，保留凹边界和不相连的多个区域。圆柱、圆锥和球沿用当前离散表面，截面是近似结果；带内孔的复杂几何体目前不支持孔洞扣除。截面暂不作为新棱柱或棱锥的底面。

## 文件与显示

新增构造保存于原有 `.mathdraw.json` 中，来源引用与对象 ID 一同保存；旧绘图可继续打开。含新构造的文件应使用 0.2.4 或更新版本。

修复了 `D_1A_1` 等相邻下标名称的公式渲染，定义和源数据不变。
