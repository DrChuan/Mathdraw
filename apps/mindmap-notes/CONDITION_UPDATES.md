# 条件作图与翻折（0.2.5）

## 条件输入

- 条件类型增加“矩形”和“定比分点”；定比分点默认比例为 1，即中点。比例表示前端到分点的距离 / 分点到后端的距离，必须为正数，采用线段内部的分点。
- 图形声明改为三项选择和成行的点名输入，名称之间用空格分隔。手动补充点线、命名规则等默认收起。
- 条件列表以自然语言和公式陈述条件；点击“编辑”或双击说明才展开原始命令。无效草稿保留并提示，求解前统一校验。
- 输入框和下拉框统一为 30px 高，并隔离主绘图界面的弹性布局规则，避免异常撑高、重叠和横向溢出。

```
rectangle(A,B,C,D)
division(M,AB)          // 中点
division(M,AB,1/3)      // AM:MB=1:3
midpoint(M,A,B)
```

上例中的注释用于说明，不属于命令。矩形和定比分点参与原有解析构造、验证、自由度及文件保存流程。

## 角度与三角函数

界面可选择度数、弧度、正弦、余弦或正切值。纯数默认按度数；包含 pi 的角度或 `rad(...)` 按弧度。

```
dihedral(BC,A,D,pi/3)
vertexAngle(A,B,C,rad(1/2))
cos(vertexAngle(A,B,C))=1/2
tan(linePlaneAngle(AP,PMD))=1/3
sin(vertexAngle(A,B,C))=1/2
```

三点角和二面角允许 0°～180°。正弦值通常对应两个角，默认分别枚举；可在表单选择 0°～90° 或 90°～180°。数学简写也可使用 `sinAcute(...)`、`sinObtuse(...)`。无向线线角、线面角限于 0°～90°，不增加补角分支。

三角函数值保留输入的分数或根式，求解时换成允许的角度分支再优先解析构造；坐标计算和回代仍使用浮点数。最多处理 64 组角度分支、显示 12 个构型，超出时不宣称已穷尽。

## 翻折

立体工具中的“翻折”：选择已创建的多边形或三角形，再选择直线、坐标轴或多边形边作为旋转轴。也可选中多边形，点击操作条中的“翻折”。

默认创建数值滑块 t（若重名则用下标），范围 −180°～180°，初值 90°。沿轴的两个定义点从前向后观察，正角遵循右手旋转方向；负角向相反方向翻折。

```
Fold(p,p.edge(1))
Fold(p,xAxis,t)
```

原面从画布和对象列表移除，转后的面作为新多边形加入。无其他可见对象引用的旧顶点也转为隐藏辅助点；轴上的顶点复用。隐藏来源保留用于联动及保存，整个翻折一次撤销。

翻折封闭多面体的一个已声明面时，其余面恢复为可单独选择的面；旧几何体保留为隐藏来源，保护既有引用。几何体模板的虚拟面应先创建为多边形再翻折。独立线段仍是独立对象，不因其恰好与旧多边形边重合而删除。

## 条件与列表交互扩展（2026-10-22）

- 添加条件区同时展示完整输入（左）和简写（右），完整输入使用紧凑控件；窄窗口自动上下排列。
- 向量线性关系：完整输入中分别填写等式两侧，例如 `AB`、`2*AC-AD`；简写可用 `vec(AB)=2*vec(AC)-vec(AD)` 或 `\overrightarrow{AB}=2\overrightarrow{AC}-\overrightarrow{AD}`。支持分数、根式系数及零向量。耦合的线性关系先解析消元，不把向量误当成长度。
- 数量积：`dot(AB,AC)=1/2` 或 `\overrightarrow{AB}\cdot\overrightarrow{AC}=1/2`；允许负数和零。单点未知时优先转为辅助平面或球面求交。
- 凸多边形：`convexPolygon(A,B,C,D)`，限定共面、凸性和输入顺序，不要求等边或等角；镜像绕行仍合法。
- 全等 / 相似：`congruent(ABC,DEF)`、`similar(ABCD,EFGH)`；也可用 `\triangle ABC\cong\triangle DEF`、`ABC~DEF`。顶点按输入顺序逐一对应，允许镜像对应，不要求相同空间朝向。相似不限定缩放比，全等的对应距离相等。先传播已知对应长度，再尝试解析构造；无法直接消元的耦合仍沿用数值求解并明确标注。
- 构型中的共面闭合线段自动形成可遮挡的面；共用顶点的多个闭环、经过线段中间分点的闭环也参与识别。非共面闭合折线不会被当成平面。边界按同一图结构生成，避免模板与普通线段重复成面。
- 对象与表达式列表增加“列表筛选”，可按点、线段、直线、曲线等类型排除，和文字搜索叠加。筛选只记入本机界面偏好，不隐藏画布对象、不改变导出或文件中的对象可见性。
