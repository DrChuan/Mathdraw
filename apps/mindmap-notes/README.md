# 枝间 · Mindgrove

macOS / Windows 本地笔记桌面程序。React、Tauri 2、Rust；应用界面和公式字体全部随安装包提供，运行时不启动本地网站服务。

## 使用

打开 `Mindgrove.app`（macOS）或 Windows 安装后的 Mindgrove。首次运行点击“选择本地笔记文件夹”，可选空文件夹或已有 Markdown 目录。

- 文件夹对应磁盘上的真实目录。Markdown 保存为 `.md`，导图保存为 `.mindmap.json`。
- `.md` 中的 `mindgrove_id` 头用于保留笔记身份；编辑界面自动隐藏它。外部 Markdown 文件可直接打开，首次保存时加入 ID。
- 支持子目录、全文搜索、重命名、移动、回收站恢复。外部文件变化会刷新界面；如果正有尚未保存的编辑，应用会保留草稿并要求另存副本或重新读取。
- 左侧文件树同时显示文件夹与笔记。右键文件夹在该目录新建，右键笔记在其所在目录新建；空白处右键在根目录新建。名称在目录树内编辑，Enter 确认、Esc 取消；选中文件后 F2 重命名、Delete 移到回收站。支持把文件和文件夹拖入其他目录。
- 目录侧栏、笔记列表、Markdown 源码与预览之间的分隔线均可拖动；双击恢复默认宽度，聚焦分隔线后可用左右方向键调整。两栏导航可分别折叠，宽度和显示状态在重启后保留。`⌘/Ctrl+Shift+B` 切换目录侧栏；`⌘/Ctrl+K` 展开侧栏并搜索。
- 隐藏侧栏后，编辑区顶栏保留“展开目录”“展开笔记列表”文字按钮；“恢复布局”可同时恢复两栏与默认宽度。系统“视图”菜单也提供对应操作。`⌘/Ctrl+Shift+L` 切换笔记列表，`⌘/Ctrl+Shift+0` 恢复默认布局。
- 所有编辑先自动写本机。单篇笔记上限 8 MB；导图上限 5000 节点，128 层。符号链接、隐藏文件和其他文件类型不会作为笔记读取或同步。

思维导图：`Tab` 添加子节点，`Enter` 添加同级，`Shift+Tab` 提升一级，`F2` 或双击编辑，`空格` 折叠，`Delete` 删除。节点编辑时 `⌘/Ctrl+Enter` 完成，`Esc` 取消；画布工具栏同时支持鼠标操作。`⌘/Ctrl+Z` 撤销，`⌘/Ctrl+Shift+Z` 重做。

节点直接在原位置编辑源码，普通 Enter 换行。光标进入 `$…$` 或 `$$…$$` 内时，节点旁只显示当前公式的预览；移到普通文字处即收起。预览在停止输入约 120ms 后更新，错误或未闭合的公式给出提示，仍可继续编辑保存。点击外部完成，Esc 恢复原文，整次编辑合并为一条撤销记录；预览不参与导图布局。

右键节点可编辑、新建、剪切、复制、粘贴、折叠和删除分支；根主题的删除、剪切和新增同级禁用。画布空白处右键可粘贴到根主题、自动布局或查看全图。画布聚焦时 `⌘/Ctrl+C/X/V` 操作整条分支；源码编辑时仍使用普通文字剪贴行为。剪贴板提供可读的 Markdown 大纲，并在同一次应用会话中保留完整分支快照，支持跨导图粘贴；外部 Markdown 标题与列表也可直接粘贴成分支。

普通拖动调整结构：节点中部接收为子节点，上方/下方插入为前后同级；无效落点恢复原位置。拖动开始时按住 Alt，整条分支自由移动。`⌘/Ctrl+F` 查找当前导图的文字或公式源码，包括折叠节点；Enter / Shift+Enter 切换结果，Esc 关闭。撤销历史按文档分别保留，切换文档后仍可使用，每篇最多 100 步，全局最多 64MiB，重启后清空。

导图默认从根节点向右展开。“自动布局”会测量节点（含公式）的实际高度，清除手动位置，按分支顺序排列并居中显示；后续文本高度变化继续参与布局。旧导图可点击一次“自动布局”重新整理，布局操作支持撤销。`⌘/Ctrl+N` 新建 Markdown，`⌘/Ctrl+Shift+N` 新建思维导图。

节点宽度随渲染内容在约 104～600 像素之间伸缩，短文字收窄，普通完整公式优先一行显示；超过上限的内容再换行。极长且无法拆分的公式仍可横向滚动查看。

“文本大纲”使用 Markdown 标题和嵌套列表；草稿自动保存，点击“应用大纲并查看导图”后更新树结构并重新布局。Markdown 笔记可以预览转换为新导图；原文保留。导图也可在笔记库中生成 Markdown 副本。支持 `$…$`、`$$…$$` LaTeX，错误公式保留源码显示。仅提供 KaTeX 支持的数学语法，不执行任意 LaTeX 程序。

## 公式列表与平面几何构造（2026-10-19）

- 对象列表默认仅显示排版后的公式。双击公式或点“编辑”后才显示源码；Enter 完成、Esc 退出。构造使用的内部辅助点不占用 A/B/C 等常用点名，也不进入对象列表；替换或删除构造后收集不用的辅助点。
- **圆点规则**：按点的当前位置与当前可见几何关系重新计算。至少两条线、边或曲线同时经过时隐藏圆点；仅一条经过或孤立时显示。与点的创建方式无关，新增、删除、隐藏、拖动、改参数和撤销都会更新。点名仍保留。
- 选中图形 → 属性 → 颜色。内置墨黑、松绿、湖蓝、鸢紫、蔷薇、陶橙、秋金、岩灰，也可自选颜色。画布、SVG、PNG 与复制图片共用颜色及统一线宽。
- **关系构造 → 轴对称**：先选直线/坐标轴/直边，再选图形。支持点、线段、向量、直线、三角形、多边形及方程/参数曲线；`Reflect(图形, 对称轴)` 的参数顺序与点选顺序不同。反射对象随原对象和轴移动；输入直线方程也可作为轴。曲线的范围随反射保留。
- **切线**：先点曲线，再点经过的点。支持曲线上点与曲线外点，有多条实切线时一并创建。`Tangent(c,A)` 或 `Tangent(c,A,序号)`；圆内点会提示没有实切线。圆采用解析构造，其余曲线采用有限范围内的数值求解，不保证找到任意复杂曲线的所有切线。
- **轨迹**：先选择路径上的主动点，再选择依赖它的从动点。自由点没有唯一的一维运动路径，需要先用“点”工具在线或曲线上建立主动点。`Locus(P,Q)` 自动使用路径区间；`Locus(P,Q,-3,3)` 指定扫描区间。坐标组合可推导时给出参数方程；一项为一次多项式时尝试消参为普通坐标方程。其他情况在后台有限采样并明确标为“数值轨迹”，不把数值拟合当成精确方程。数值轨迹用于显示，关联点请建立在原构造上。一般隐式曲线需先改用参数路径；轨迹功能用于平面作图。
- **度量**：长度点选边或两个点；角度依次点选边上的点、顶点、另一边上的点；面积和周长点选三角形/多边形内部或圆。数值标注随来源更新，可拖动。命令为 `Length(s)`、`Length(A,B)`、`Angle(A,B,C)`、`Area(p)`、`Perimeter(p)`；角度取 0～180°。
- **角平分线**：主按钮默认作射线，下拉可选完整直线；依次选 A、顶点 B、C。定义为 `AngleBisector(A,B,C)` 或 `AngleBisectorLine(A,B,C)`。重合点和平角会给出失效提示。
- 选中三角形后，浮动操作条提供“外接圆 / 内切圆”，对应 `Circumcircle(p)`、`Incircle(p)`，也可传三个点；随三角形变化。基本图形栏直接显示“圆心＋圆上一点”“圆心＋半径”，三点圆保留在更多方式中。
- 新构造保存为现有 v2 绘图文件的扩展字段，原对象 ID 与依赖关系继续保留。旧文件可读取；更新前程序不支持新增构造类型。新增功能不改变笔记格式或 COS 协议。

## 滑块与关联作图（2026-10-18）

- 滑块手柄即时响应，几何数值按显示帧合并更新；复用后台曲线计算，处理中只保留最新请求，拖动时快速采样、松手后精细绘制。整次拖动为一次撤销，保存或退出前会提交最后一个数值。
- 点的小圆点根据当前可见的线和曲线判断。创建、移除、隐藏、恢复或修改图形后会重新计算；孤立点恢复圆点，点名和坐标标签保留。选择手柄仍只用于编辑，不进入输出。
- 平行线、垂线先选点或先选参考线均可；已选对象后切换工具也会带入。选点时可直接点击未创建的交点，交点与构造一起提交、一起撤销；取消预览不留下对象。坐标轴悬停、选中时高亮。
- 表达式区底部“添加 / 参数曲线 / 构造命令”并列，点击“参数曲线”直接填入可修改的模板并预览，按 Enter 添加。工具栏及构造命令内的入口继续保留。

## 独立数学绘图 Mathdraw（2026-10-18）

双击 `artifacts/mathdraw/Mathdraw.app` 即可直接进入绘图；也可使用根目录的“启动数学绘图.command”（Windows 为同名 `.cmd`）。不需要打开笔记库。独立版使用自己的恢复草稿与设置；笔记版“工具 → 数学绘图”继续可用，两者共用 `.mathdraw.json` 文件格式。

- 选中 x/y 轴可直接作平行线、垂线和交点；轴不进入对象列表。定义中可用 `xAxis`、`yAxis`，引用会保存所用工作平面的身份。隐藏坐标系不会破坏已有构造。选中垂线后，在旁边操作条勾选“显示垂直符号”，图面和导出都会显示直角标记。
- “方程曲线 → 参数曲线”，或输入 `Parametric(cos(t), sin(t), 0, 2*pi)`。四个参数依次为 x(t)、y(t)、参数起点、终点，支持当前工作平面、LaTeX、关联数值、曲线上的点、指定坐标及求交。
- 选中曲线后点击“取值范围”，分别填写 x/y 上下限，再点击“应用范围”。空白表示不额外限制，仍遵循原表达式自然定义域；“恢复自然定义域”清除四项限制。参数曲线另外保留定义中的 t 区间。绘制、依附点、交点及导出使用相同限制。
- `B=(x(A)+1,y(A)/2)`、`n=x(A)`、`y=x(A)*x+y(A)` 引用点 A 的当前坐标；拖动或重命名 A 后保持关联。空间自定义坐标系中的 x/y/z 引用使用该坐标系坐标，循环依赖会被拒绝。
- 输入 `y=kx+1` 时，未定义的 k 自动创建为数值 1 和滑块，和曲线一起撤销。支持 `2kx`、`a_{123456}x` 或 `a_123456*x`。新变量名仅为单字母，可带字母/数字下标；与后续变量相乘时，下标用花括号括住或写 `*`。保留 x/y/z、u/v、pi/e 和函数名的已有数学含义。无效定义不提交变量或图形。

独立版开发：`npm run drawing:dev`；独立版打包：`npm run bundle:drawing -- --target universal-apple-darwin --bundles app`（在本目录执行）。Windows 使用同一脚本并选择 `--bundles nsis,msi`，分别生成 Mathdraw 安装包。现有笔记版打包命令保留。

## 绘图数值与坐标系（2026-10-17）

在“新增定义”输入 `m=1` 创建数值与滑块；可展开“滑块范围”修改最小值、最大值和步长。`A=(m,2)`、`c: y=m*x^2`、`Circle(O,m)` 等定义随数值更新；`n=2*m` 创建关联计算值。数值改名保留引用。几何对象数量、交点分支序号等离散结构参数仍使用固定整数。

新建绘图自带可吸附、可引用的原点 `O`。工具栏“显示坐标系 / 隐藏坐标系”控制轴的显示，隐藏后仍可引用原点。空间坐标轴仅画正半轴；空间总览保留绕 z 轴的滑块及精确角度输入。

新建圆锥曲线自动附带关联焦点：椭圆、双曲线为 `F_1/F_2`，抛物线为 `F`；已有同名对象时使用下一个可用名称。圆不生成焦点，方程圆与三点圆生成关联圆心 C；由已知圆心创建的圆复用已有圆心。旧版圆的自动焦点改为圆心，有其他构造引用的点保留身份或别名关系。焦点失效时暂时隐藏，方程恢复有效后重新显示。旧绘图中的曲线不自动补焦点，以免重复已有手动作图。

“立体工具 → 空间坐标系”依次选择原点、x 正方向上的点、几何体平面面作为 xOy 平面、面内的 y 正方向，选完直接创建。z 正反可在选点过程中设置，默认右手系 `z=x×y`，左手系为 `z=−(x×y)`。方向点只决定朝向，轴会继续延伸；y 的正向由所点位置处于 x 轴哪一侧确定，并始终保持与 x 垂直。预览同时显示 z 的原空间方向。“上一步”可退回重选。原点、x 与 y 方向必须在所选面的平面内。

### 工具与鼠标操作

- 顶部第一层集中“选择 / 框选”“平移画布”、撤销、全图、坐标系及属性。框选模式下空白拖动选择多个对象；平移模式下拖动任何位置只移动视图。空格或中键临时平移，Esc 返回选择模式。
- 作图工具分为“基本图形”“关系构造”“方程曲线”“立体工具”。点击工具后，画布底部说明当前操作和下一步。切换分类会取消未确认的构造；已提交的图形保留。
- 新建、打开和另存为归入“文件”；SVG、PNG 归入“导出”，复制图片仍直接可用。工作平面创建集中在“新建平面”；工作平面与观察视角分开显示。
- “指南”说明逐点作图、精确修改和鼠标快捷操作；圆的三种创建方式在“基本图形 → 圆”中选择。四心和内外接球仍由适用的选中对象唤出。

### 吸附、标签与截图

- 显示坐标系时，靠近 x/y 轴描点会吸附并建立轴点关联；空间中可吸附当前作图平面内的可见轴。拖动轴点仍留在轴上，Alt 临时忽略吸附。
- “点”工具在两条曲线交叉处点击会直接创建预览中的关联交点，不弹重叠对象列表；选择工具仍保留重叠对象选择。
- 点名及原点 O 的标签均可单独拖动，保存标签偏移并支持撤销，不改变点坐标。画布禁用系统文字选择，避免拖动时出现蓝色文字选区。
- 绘图定义中可直接输入 `a/b`、`x^2/9`、`(x+1)/(x-1)`；预览按正常上下分式排版，编辑源码与计算语义保留。
- 图形和坐标轴共用向内留白的矩形绘图区。无限直线、双曲线等裁切至同一边界，SVG/PNG 使用相同图面。

## COS 同步

设置中填写 AccessKey ID（腾讯云 SecretId）、SecretAccessKey（SecretKey）、完整桶名（含 APPID）、地域和前缀。其他电脑连接同一桶与前缀即可同步。每个本地笔记库应使用独立的云端前缀。连接设置按本地笔记库分别保存，切换目录不会自动混用云端空间。

密钥保存在 macOS 钥匙串 / Windows 凭据管理器，不写入笔记文件、配置 JSON 或日志。客户端 Rust 进程直接通过 HTTPS 和 S3 Signature V4 访问 COS；不需要应用服务器，也不需要浏览器 CORS 配置。

使用专门的子用户密钥，仅授予指定桶/前缀的 `GetBucket`（列举前缀）、`GetObject`、`PutObject` 权限。应用不要求公开桶、不修改桶策略，也不调用远端对象删除接口。连接检查验证列举权限；首次实际同步会验证读取/写入权限。

云端写入 `<prefix>/records/<路径哈希>/<版本ID>.json`。每个版本记录包含相对路径、内容、父版本、文件哈希、设备标识和删除状态。对象不可变，因此同时编辑不会互相覆盖版本。发现分歧时保留两份内容，生成带时间、设备和版本标记的冲突副本；删除与修改冲突时保留修改。应用不会把 COS 对象名称直接拼为绝对本地路径。

自动同步在本地保存后及每 30 秒进行；也可手动同步。失败时本地编辑与待上传版本保留，下次重试。同步期间再次修改的文件会推迟应用云端更新，避免覆盖正在编辑的内容。

`.mindgrove/` 保存本机回收站、同步基线和待上传版本。不要单独删除这套元数据；整体迁移笔记库时请连同隐藏目录一起备份。云端保留历史版本，首版不自动清理历史。恢复回收站内容后再同步会产生新的有效版本。云端笔记内容未做客户端端到端加密，访问由 COS 私有桶权限控制。

## 开发与打包

需要 Node.js 22.12+ 或 26，以及 Rust 稳定版。Mac 需要 Xcode Command Line Tools；Windows 需要 Visual Studio C++ Build Tools 与 WebView2。

```sh
cd apps/mindmap-notes
npm ci
npm run desktop       # 独立桌面窗口，开发模式
npm run bundle        # 当前平台桌面包
npm test              # 大纲转换、公式保留和格式校验
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

根目录 `npm run notes` 或「启动枝间.command」会打开本地应用，尚未打包时先构建。根目录原有 `npm start` 仍启动世界史应用。

macOS `.app` 输出：`src-tauri/target/release/bundle/macos/Mindgrove.app`；Mac 通用版可用 `npm run bundle -- --target universal-apple-darwin --bundles app` 构建，输出位于 `target/universal-apple-darwin/release/bundle/macos/`，须先安装两个 Mac Rust 目标。Windows NSIS/MSI 位于 `src-tauri/target/release/bundle/`。构建必须在对应操作系统完成；仓库提供 macOS/Windows GitHub Actions 工作流。当前未配置开发者证书或自动更新服务；内部使用的包为本地构建，公开分发前需签名和公证。

## 数据边界

## 图片与紧凑导图（2026-10-16）

在 Markdown 源码区或双击后的节点编辑框中，直接 `⌘/Ctrl+V` 粘贴剪贴板图片。支持 PNG、JPEG、WebP、GIF，单张最大 2 MiB，单篇仍受 8 MiB 上限约束。图片以标准 Markdown data URI 保存在笔记中，复制笔记、回收站恢复、冲突副本及 COS 同步均包含图片；不依赖外部图片服务器。源码中可见编码后的图片内容，首版未提供独立附件目录与图片裁剪。节点里的图片限制显示尺寸，自动布局使用最终实际尺寸。粘贴后立即完成编辑或退出会等待图片读取完成。

普通节点上下内边距缩为 8px、根节点为 10px，默认分支间距为 18px；已有手动位置可点击“自动布局”重排。

## 数学绘图

原生菜单“工具 → 数学绘图”（`⌘/Ctrl+Shift+D`）打开独立窗口，无需打开笔记库。新建、打开、保存、另存为及恢复草稿独立于笔记，源文件为 `.mathdraw.json`。关闭窗口或切换平面/立体模式前处理未保存内容；切换模式会创建新画布。文件保存检查外部修改，失败时保留草稿。

- 平面支持点、线段、向量、直线、三角形、多边形、圆锥曲线与一般显式/隐式曲线。可直接点选画布，或在表达式列表输入定义；坐标允许数值算式，多边形按轮廓顺序选取 3～64 个共面顶点，可为简单凹多边形。
- 方程使用 LaTeX 源码与同步预览，例如 `\frac{x^2}{9}+\frac{y^2}{4}=1`、`y=\sin{x}`。支持分式、根式、上下乘方、常用三角函数、对数、指数、绝对值和 pi/e；不是完整 LaTeX 计算系统。旧版普通数学表达式仍可打开。预览允许未完成输入，绘制/完成时检查受限语法；不执行 JavaScript。
- 点工具输入 `1,c` 表示曲线 c 上横坐标为 1 的点，`c,2` 表示纵坐标为 2。多解全部生成；一般隐式方程在设置的曲线范围内求解，显式函数可直接求值。没有解时提示；派生点随原曲线更新。
- “交点”选择两条直线、线段、向量、曲线或多边形/几何体的边，生成当前计算范围内的全部交点。直线为无限延伸；线段与向量只在端点之间求交。空间直线支持相交检查；曲线求交要求位于同一工作平面。一般曲线采用数值求解，接近重合、奇异或极密集交点可能需要缩小范围。
- 选中边可取中点、n 等分点；三角形支持重心、外心、垂心、内心。构造失效时隐藏，来源恢复后重新显示。删除来源前提示受影响对象。
- 立体模式默认正视 z=0 平面，坐标轴默认不显示。可创建坐标平面、方程平面、三点平面；点可输入局部二维坐标或全局三维坐标。拖动自由点限制在工作平面内。
- 除常见几何体外，可选多边形/三角形底面，以侧棱向量（方向及长度）建立一般棱柱，以任意顶点建立一般棱锥。底面和顶点保持关联；棱柱的侧棱向量可在属性栏调整。
- 选择多面体可创建外接球或内切球；按 Shift 点击顶点手柄或点列表可多选顶点后创建外接球。外接球要求至少四个不共面的点且全部共球；不唯一时要求补充顶点。内切球检查凸多面体全部面是否能同时相切，不存在时弹框说明。球随原构造更新。
- 新画布默认正交轴测，保留斜二测选项。两种投影均仅绕全局 z 轴旋转；正交投影保持投影基正交，斜二测固定纵深轴 45°、长度减半，旋转后的斜切外观属于该投影本身的性质。旧文件保留原投影。
- “建立坐标系”依次选择/输入原点、x 正方向上的点、y 正方向上的点，并选择 z 正反。x、y 方向须垂直。工作平面与坐标系互相独立，不会重定位已有几何对象。
- 图面统一线宽，坐标轴和向量采用填充的燕尾箭头；同一位置被至少两条曲线或直线经过时隐藏圆点；仅一条或零条经过时显示圆点，保留标注。遮挡边自动分段为虚线，每条边可指定实线、虚线或隐藏。
- 图面文字使用系统 Times New Roman，缺字或字体缺失会明确提示，可选择字体文件。导出 SVG 默认将文字转轮廓；PNG 默认透明、宽 1600px，也可白底及自定大小。复制图片使用相同导出场景，适合粘贴到 Word。编辑手柄、选择高亮与辅助网格不进入输出。

数学绘图源文件暂不加入笔记库/COS；可把导出的图片直接粘贴到笔记或导图。

### 画布与表达式工作区（v2）

- 顶部按点、线、圆、多边形、构造分组。选工具后按底部提示点选：线段点两次，三角形点三次；多边形点首点或 Enter 闭合。完成后保留当前工具，可连续作图；Esc 先取消未完成构造，再次按下返回选择。预览和临时端点不写入源文件，完成后一次撤销。
- 默认点击选择，Shift 增减选择，空白拖动框选；空格拖动或中键平移，滚轮缩放。默认按屏幕距离吸附已有点、交点、线和曲线，并建立关联；Alt 暂时关闭，网格吸附单独开启。重叠时弹出候选对象菜单。
- 选中边后在图旁直接取中点、等分、作平行线、垂线或垂直平分线；选中三角形可取四心。右键可隐藏、锁定、重命名、定位来源和删除；删除前列出依赖构造。派生点显示来源，不能被普通拖动改成自由点；`On` 构造的点可沿原线或曲线拖动。
- 左栏显示对象符号、定义、LaTeX 预览及计算结果，可搜索、调宽或折叠；右侧属性栏默认收起。对象符号与图上标签分别管理。编辑定义保持对象 ID，引用随符号改名自动更新；图上拖点也更新定义。修改已有行在约 180ms 后应用，一次连续编辑为一步撤销；无效源码保留草稿和最后有效图形。新行在画布显示临时预览，Enter 正式添加；临时预览不参与保存和导出。命令菜单支持中文搜索和参数说明，Shift+点击图形可插入引用。
- 示例：`A=(0,0)`、`B=(4,0)`、`s=Segment(A,B)`、`M=Midpoint(s)`、`c: y=\frac{x^2}{2}`、`P=On(c,1)`、`l=Perpendicular(s,P)`。圆可用 `Circle(A,B)`、`Circle(A,2)`、`Circle3(A,B,C)`；曲线坐标点可用 `PointX(c,1)` / `PointY(c,2)`。构造命令使用对象符号，不要求记住内部 ID。
- 立体模式分别选择“工作平面”和“观察视角”。新点落在工作平面；正视编辑与空间总览互不混淆。可选三个点、多边形或几何体平面面建立工作平面。棱柱点选底面后拖动预览高度，或输入精确侧棱向量 / 已有向量名；棱锥选底面再选顶点或输入空间坐标，确认前显示整体预览。内外接球位于适用选择的构造菜单；坐标系按原点、x/y 正方向及 z 正反逐步选择。
- 文件升级为 v2，兼容打开 v1 且保持旧对象 ID。首次保存旧文件时可取消、另存升级副本或保存 v2；旧版程序无法读取新格式。未完成表达式单独保存在本机恢复草稿中，不写入绘图源文件或云端，关闭与切换文档前仍有保存保护。

交互参考：[GeoGebra 多边形工具](https://geogebra.github.io/docs/manual/en/tools/Polygon/)、[Desmos Geometry 工作区](https://help.desmos.com/hc/en-us/articles/15316366009997-Getting-Started-Desmos-Geometry)。


### 文字、配色与轨迹修复（2026-10-19）

- 文字工具直接输入内容，无需引号；支持文字和 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 公式混排及实时预览。源码命令支持 `Text("内容",(x,y))`，并兼容外层弯引号和未双重转义的 LaTeX。图面和导出仍采用 Times New Roman；错误公式保留文字。
- 颜色改为纯色正方形，可选择系统颜色或输入六位十六进制颜色值。
- 坐标引用支持 `G=(x(D),y(D))`，同时兼容带空格、全角括号和 LaTeX 正体函数名的输入，派生坐标继续跟随原点。
- 椭圆、圆、抛物线、双曲线上的主动点可用于轨迹。对称点及坐标构造点可作为从动点；双曲线保持主动点所在分支。可推导的轨迹显示参数方程，其他情况保留数值轨迹，不包含通用符号消元系统。

### 交点、颜色收藏与轨迹方程（2026-10-19）

- 批量创建交点时，每个点分别分配可用符号和相同显示名称；打开旧文件时修复旧版批量交点均显示 I 的情况，保留对象 ID 和依赖。
- 对称等同时支持点和图形的选择阶段，已有点仍可高亮；高亮已有点与在曲线上创建新点的预览分别控制。
- 自定义颜色可以“添加到调色板”，在本机程序中跨文档、跨重启复用。“已使用的颜色”记录当前画布对象曾使用的颜色，改色或删除对象后保留；以绘图 ID 在本机保存，不写入绘图源文件或同步到其他设备。相同绘图 ID 的另存副本共享这份本机颜色历史。
- 轨迹的方程以 LaTeX 显示。常见圆锥曲线及其仿射变换、单个三角函数的多项式坐标关系，可精确消去参数；优先显示直角坐标方程。不能消参时以方程组显示参数公式；不能精确组合时保留数值轨迹。显示所在曲线方程时仍标明扫描区间，有限区间或双曲线分支不会扩成整条曲线。不使用采样点拟合来冒充精确方程。
