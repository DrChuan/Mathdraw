# 条件作图：优先构造，再处理未覆盖的关系

## 求解顺序（0.2.3）

每组条件都会先经过几何构造规划，不能直接构造的部分才使用数值迭代。

1. 传递已知长度、等长、长度比及棱柱对应边关系。用余弦定理将可用的两边夹角转成距离；无向线线角枚举两种顶角。
2. 构造正多边形、正方体；利用向量加法构造平行四边形及棱柱对应顶点。棱台先消去相似底面的偏移，再构造顶面。
3. 将距离转成球面、共线转成两辅助平面、共面及可转换的平行/垂直关系转成辅助平面；等距转成垂直平分面，距离比转成阿波罗尼斯球面。可用的角度、线面角、二面角条件也转为相应轨迹。
4. 球面之差得到根平面，与其他平面做线性消元，最后解至多一个二次式。有限交点分别保留；连续的圆、球面、直线或平面保留自由度，不伪装成唯一解。
5. 回代**全部原条件**，剔除退化、自交底面、不满足线段范围等候选位置。整体平移和旋转只消去坐标选择自由，空间镜像分别保留。
6. 无法逐点构造的耦合关系使用已构造的部分作为起点，继续阻尼最小二乘求解。失败起点会扰动，避免同一模板重复跑同一次搜索。

拖动时先检查目标是否直接落在解析轨迹上；如有从动点，优先保持参照结构并重新进行轨迹求交。连续轨迹优先采用离原位置最近的候选。不能直接构造时再进行数值校正。

辅助轨迹仅存在于计算过程，不添加可见对象或占用对象列表。求解结果中可展开查看构造步骤。

## 截图中的四棱柱

条件：`prism(A,B,C,D,A_1,B_1,C_1,D_1)`、`AA_1 ⟂ ABC`、`AD=√3`、`AB=3`、`AA_1=3`、`BC=CD=2`、`lineAngle(AB,BC,60)`。

一个精确构型为：

```
A=(0,0,0)  B=(3,0,0)  C=(2,√3,0)  D=(0,√3,0)
A_1=A+(0,0,3)  B_1=B+(0,0,3)  C_1=C+(0,0,3)  D_1=D+(0,0,3)
```

旧求解器将所有顶点当作独立坐标，最小化归一化条件残差。模板初始化覆盖了随机位置，导致没有找到第一个解时，32 次重试的初始形状完全相同，重复落入同一局部极小值。这不是条件矛盾。

现在此例使用两种线线角分支、圆交点及直棱柱平移直接构造，排除自交底面后保留上下两种空间镜像。结果不依赖随机种子和搜索时长。

## 精度与边界

- “解析构造”表示按几何公式、线性消元和轨迹求交计算；坐标存储、三角函数与回代仍使用浮点数，**不是完整的符号代数引擎**。
- 条件中的分数、根式源码保留；坐标显示可以识别简单分数与根式，不能将这种显示识别当作符号证明。
- 仅在所用构造产生有限候选、候选未被截断且均已处理时声明有限分支枚举完成。连续自由度、时间预算耗尽或候选上限触发时不声明穷尽。
- 构造尚未覆盖所有非线性耦合关系。数值回退中的“未找到”不等于“无解”；校验残差是回代的浮点偏差。
- 规划有时间及候选数量限制，运行于现有可取消 Worker 中；继续搜索不重复返回上一轮的相同构造采样。

相关实现位于 `src/drawing/constraints/{construction,metric,intersections,planner,solver}.ts`。

## 共有顶点回归修复（0.2.3）

去掉上述四棱柱的垂直条件时，通用构造会优先放置 A、C，再构造 B。此时 `lineAngle(AB,BC,60)` 的两条线都包含尚未求出的 B，不能将 BC 当作已知方向读取。旧代码遗漏了这个检查，会产生读取 `undefined[0]` 的错误。

现在先识别共有未知顶点：一般夹角通过已推导的距离求交及原条件回代处理；共有顶点的平行线使用共线轨迹，垂直线使用以另两个端点为直径的球面。含共有未知顶点的线面关系没有可直接应用的构造规则时，保留原条件供回代及数值处理，不读取尚未确定的参考对象。轨迹提取也使用相同检查。

不含垂直条件的这组棱柱保持侧棱方向的两项自由度，不能自动补上直棱柱限制。
