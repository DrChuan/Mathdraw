## 1023bug

- 部分条件得出的点轨迹是候选范围，不是完整条件体系的轨迹。`complete=false` 的解析候选不再进入画面、导出、拾取或全图取景。数值轨迹只显示回代全部条件验证过的采样路径；数值路径不宣称完整。
- 几何体声明的面作为稳定边界保留，边上有内点、重合点或内部弦时不移除原面。旧文件缺少的声明面在读取时补齐，点的 ID、样式和已有引用保留。
- 声明多面体按自己的完整外壳成体，辅助剖分面不阻止成体。PBC 恢复为遮挡面。
- 条件体系列表按点、线、面、轨迹、其他分组；包括固定点、隐藏对象、成体后的面和同一条件体系的后续派生对象。分组和折叠不改画面显示。跨多个独立条件体系的对象保留在根列表。

## 工具范围及处理

| 工具 | 立体处理 |
| --- | --- |
| 点、线段、直线、向量 | 使用真实三维坐标；新点在工作平面，边上点沿真实边参数定位 |
| 三角形、多边形 | 三维共面性校验，真实表面和遮挡；不共面时提示 |
| 中点、等分、四心 | 三维向量计算，随来源联动 |
| 平行线 | 过空间点沿参考线真实方向 |
| 过点作线的垂线 | 点在线外：通过正交垂足；点在线上：需包含参考线的工作平面消除不唯一性 |
| 过点作面的垂线 | 可先选点或先选面；沿面的真实法向量 |
| 平行平面 | 选面和空间点，创建随来源联动的平面；以有限虚线轮廓示意，不把任意方向的直线冒充平行平面 |
| 垂直平分线 | 需选择包含线段的工作平面；空间中不指定平面时不擅自挑一条线 |
| 圆心＋半径 / 圆心＋圆上一点 | 圆心处平行于所选工作平面的圆；圆上一点必须位于此平面 |
| 三点圆、内外接圆 | 根据三个来源点动态确定真实平面，不限制在 z=0；退化时失效提示 |
| 切线 | 在曲线真实平面中求切线，检查空间点共面性；不把空间点投影后计算 |
| 交点 | 三维直线求交，异面线无交点；共面曲线先统一局部坐标基再求交；非共面曲线明确提示范围限制 |
| 轴对称 | 空间中为绕轴半周旋转；点线曲线均使用真实空间轴和来源平面 |
| 角平分线 | 在两条角边所确定的真实三维平面计算，平角不冒充唯一方向 |
| 长度、角度、面积、周长 | 用三维距离、角平面、表面面积计算；几何体的面可单独选择度量 |
| 空间轨迹 | 使用满足全部条件的解析/采样轨迹；通用独立空间轨迹未实现时明确提示，不投影成平面轨迹 |
| 方程曲线、参数曲线 | 在明确的当前工作平面内定义，保留真实空间位置 |
| 翻折、法向量、截面 | 使用三维轴旋转、平面法向和实际多面体壳求交；保留原有有效性检查 |
| 棱柱、棱锥、几何体模板 | 使用三维底面、侧棱向量或顶点，不使用屏幕方向代替空间方向 |
| 坐标系、工作平面、文字 | 使用所选三维点、面和工作平面；观察视角不改变几何数据 |
